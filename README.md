# V S Enterprises Attendance App

Professional Android starter project for V S Enterprises.

## Planned production modules
- Employee/Admin authentication
- Employee profile and mobile number
- Check-In / Check-Out
- 8-hour or 12-hour timed location sharing
- Live team map for authorized employees
- Attendance history and monthly reports
- Firebase Authentication + Firestore
- Foreground location service with explicit employee permission
- Automatic location stop at duty-duration expiry

## Required before a production APK
1. Create a Firebase project.
2. Enable the authentication method (Phone or email/password).
3. Add the Android app using the application id `com.vsenterprises.attendance`.
4. Add the Firebase `google-services.json` file to `app/`.
5. Enable Firestore.
6. Create/configure a Google Maps API key for the map screen.
7. Build the APK with Android Studio.

This archive contains the professional login UI and Android project foundation. Firebase credentials/API keys are intentionally not embedded.
